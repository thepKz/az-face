# AZ FACE showcase

Public customer demonstration built with Next.js, React and GSAP.

## Run

Use Node.js 24: `npm ci`, then `npm run dev`. Verify with `npm run typecheck` and `npm run build`.

## Vercel

Import this repository as a Next.js project. Use the repository root, default build command and no environment variables.

## Content and scope

This deployment contains a snapshot of published demonstration content in `src/content/published.json`. Images illustrate the design and do not document actual client outcomes. The contact flow prepares a local summary; it does not transmit a booking. Search indexing is disabled.

The authenticated Payload CMS, PostgreSQL database, draft content and editorial preview remain in the separate local authoring project. No credentials or personal source documents are included here. Re-export published content when editorial changes are ready.
